# Homepage Hero Video

Use only AinerWise-owned or properly licensed footage here.

Default expected asset:

- `ainerwise-smart-building-hero.webm`

The homepage also supports:

- `NUXT_PUBLIC_HOME_HERO_VIDEO_WEBM`
- `NUXT_PUBLIC_HOME_HERO_VIDEO_MP4`

Do not copy KNX or other third-party website media into this folder. The hero
component automatically falls back to the in-house 3D scene if video loading
fails.
